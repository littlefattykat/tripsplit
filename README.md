# TripSplit GitHub Ready v2

Upload `index.html`, `manifest.webmanifest`, `sw.js`, and `icon.svg` to the repository root. In GitHub: Settings > Pages > Deploy from a branch > main > /(root).

## v2 changes
- New ALL button in Paid for, with high-contrast dark text on lime
- Natural language phrases including `for all` select ALL automatically
- Explicit `splitMode: all | selected` expense model
- Three trip tabs: Expenses, Balances, and Who pays whom
- Who pays whom nets all member balances and shows only final settlement transfers
- Multi-currency settlement choice
- Local JSON backup and restore
